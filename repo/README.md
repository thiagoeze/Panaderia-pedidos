# Sistema de Gestión de Pedidos para Panadería

Proyecto Final — Ingeniería del Software
6.º Bachillerato Tecnológico en Informática
Escuela Técnica Catalina Harriague de Castaños — Año lectivo 2026

## Descripción

Sistema web para la gestión de pedidos de una panadería, que permite a los
clientes registrar pedidos en línea y al personal administrarlos de forma
organizada, reemplazando la gestión manual actual (papel, llamadas, WhatsApp).

## Estructura del repositorio

```
/docs   -> documentación del proyecto (requisitos, UML, actas de sprint)
/src    -> código fuente del sistema
/tests  -> casos de prueba
```

## Flujo de trabajo

- `main` — versión estable del proyecto.
- `develop` — integración de funcionalidades en desarrollo.
- `feature/nombre-funcionalidad` — desarrollo de cada nueva funcionalidad.

Toda incorporación a `develop` o `main` se realiza mediante Pull Request,
revisado por al menos un integrante del equipo antes del merge.

## Convención de commits

- `feat:` nueva funcionalidad
- `fix:` corrección de errores
- `docs:` cambios en documentación
- `chore:` tareas de mantenimiento o configuración
